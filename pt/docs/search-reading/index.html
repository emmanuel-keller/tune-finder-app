    Pesquisar e ler páginas PDF

    Selecione um livro, encontre títulos e abra a página certa.

    Mostrar instruções para

    Escolher o livro para pesquisa gratuita

    1. Abra Livros e um livro com índice aceite.
    2. Use Usar na pesquisa se não estiver Selecionado para pesquisa.
    3. Volte a Pesquisa.

    Mudar é gratuito e preserva os restantes livros/índices. Busca em vários livros pesquisa vários; ficheiros sincronizados não desbloqueiam a compra.

    Pesquisar um título

    1. Escreva parte do título.
    2. Leia livro e página/intervalo de cada resultado.
    3. Toque no pretendido para abrir o PDF.

    A pesquisa usa o índice aceite, não todo o texto PDF. Guarde OCR/edições primeiro. Um título pode surgir em páginas ou livros diferentes.

    Ler e adicionar um tema

    Percorra páginas e toque para ocultar/mostrar navegação. + adiciona o tema a uma playlist. Detalhes também abre PDF sem índice. Para uma página errada, corrija o intervalo, não o original.

    Resultado ou PDF em falta

    Verifique seleção, índice guardado, ortografia e PDF; tente um título mais curto. Pode existir índice sem PDF, logo um resultado não garante leitura. Restaure o PDF correspondente. Uma referência de playlist pode manter título/página anterior após correção do índice. Reveja-a e substitua se necessário. Consulte Resolução de problemas.
