    Rechercher et lire les pages PDF

    Choisissez un recueil de recherche, trouvez les titres et ouvrez la bonne page PDF.

    Vérifié avec TuneFinder 1.5.5

    Afficher les instructions pour

    Choisir le recueil de recherche gratuit

    1. Ouvrez Recueils et touchez un recueil avec un index enregistré.
    2. Touchez Utiliser pour la recherche s’il n’est pas déjà Sélectionné pour la recherche.
    3. Revenez à Recherche.

    Ce choix peut être changé gratuitement. Les autres recueils et index restent dans la bibliothèque. La Recherche multi-recueils recherche dans plusieurs index à la fois ; les fichiers synchronisés seuls ne l’activent pas.

    Rechercher un titre

    1. Saisissez une partie du titre dans Recherche.
    2. Lisez le nom du recueil et la page ou plage PDF de chaque résultat.
    3. Touchez le résultat souhaité pour ouvrir son PDF.

    La recherche utilise le texte de l’index enregistré, pas tout le texte PDF. Enregistrez les propositions OCR ou modifications manuelles avant de les attendre dans les résultats. Des titres répétés peuvent figurer à différentes pages ou dans plusieurs recueils.

    Lire et ajouter un morceau

    Faites défiler les pages PDF. Touchez une page pour masquer ou afficher la navigation. Le bouton + du lecteur ajoute le morceau affiché à une playlist ; consultez Playlists.

    Les détails permettent aussi d’ouvrir un PDF sans index. Si le résultat ouvre la mauvaise page, corrigez sa plage de pages PDF plutôt que de modifier le PDF d’origine.

    Résultat ou PDF manquant

    Vérifiez le recueil sélectionné, l’index enregistré, l’orthographe et la présence du PDF. Essayez un titre plus court. Un index peut être disponible sans PDF : trouver un résultat ne garantit pas l’ouverture de ses pages. Restaurez le PDF correspondant dans les détails et réessayez.

    Une référence de playlist peut conserver un ancien titre ou numéro après correction de l’index. Vérifiez-la et remplacez l’entrée si nécessaire. Consultez les Dépannages pour les erreurs persistantes.
