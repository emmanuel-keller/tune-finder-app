    Buscar y leer páginas PDF

    Selecciona un libro, busca títulos y abre la página correcta.

    Verificado con TuneFinder 1.5.5

    Mostrar instrucciones para

    Elige el libro de búsqueda gratuita

    1. Abre Libros y un libro con índice aceptado.
    2. Toca Usar para buscar si no está Seleccionado para buscar.
    3. Vuelve a Buscar.

    Cambiar es gratuito y conserva los demás libros/índices. Búsqueda en varios libros busca en varios; archivos sincronizados no desbloquean la compra.

    Busca un título

    1. Escribe parte del título.
    2. Lee nombre del libro y página/rango de cada resultado.
    3. Toca el adecuado para abrir el PDF.

    Se busca texto del índice aceptado, no todo el PDF. Guarda OCR/ediciones antes. Un título puede aparecer en diferentes páginas o libros.

    Lee y añade un tema

    Desplázate por el PDF y toca la página para ocultar/mostrar controles. + añade el tema a una lista. Detalles también abre el PDF sin índice. Si abre una página incorrecta, corrige el rango, no el original.

    Resultado o PDF ausente

    Comprueba selección, índice guardado, ortografía y PDF; prueba un título corto. Un índice puede existir sin PDF, por lo que un resultado no garantiza lectura. Restaura el PDF correspondiente. Tras corregir un índice, una referencia de lista puede conservar título/página anterior; revísala y reemplázala si hace falta. Consulta Solución de problemas.
