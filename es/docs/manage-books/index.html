    Gestionar libros y archivos

    Busca, renombra, reemplaza o elimina elementos distinguiendo PDF e índices.

    Mostrar instrucciones para

    Encuentra un libro

    En Libros, filtra nombres con la búsqueda. La lista alfabética muestra PDF e índice disponibles. Toca la fila para sus acciones.

    Usa el catálogo

    1. Toca Explorar el catálogo.
    2. Elige la edición correspondiente.
    3. Usa Descargar índice si hay índice inicial y Elegir PDF… para tu copia.
    4. Comprueba las páginas: las ediciones pueden diferir en títulos y numeración.

    El catálogo no proporciona PDF protegidos. Los libros con PDF o índice local aparecen en la biblioteca. Adapta el índice inicial a tu documento.

    Renombra un libro personal

    1. Abre sus detalles y Gestionar archivos.
    2. Elige Renombrar, escribe el nombre y Guardar cambios.
    3. Busca el nuevo nombre en la biblioteca.

    Renombrar conserva la identidad y referencias de listas. No renombra los libros del catálogo.

    Reemplaza o elimina archivos

    Reemplazar PDF elige un reemplazo. Conserva el original hasta abrir correctamente el nuevo. Revisa las páginas del índice o genera otro si ya no coincide. Eliminar índice conserva el PDF; Eliminar PDF conserva el índice. Verifica el libro antes de confirmar. Las eliminaciones aceptadas pueden propagarse con la sincronización a dispositivos de la misma plataforma; sin conexión o en pausa quedan pendientes para después.

    Elimina un libro personal

    Eliminar documento elimina sus archivos de la biblioteca tras confirmar, pero no el PDF original en la otra app. Las referencias de listas se conservan y pueden quedar inaccesibles: elimínalas o repáralas deliberadamente. No elimines archivos para reparar OCR o sincronización. Consulta Solución de problemas.
