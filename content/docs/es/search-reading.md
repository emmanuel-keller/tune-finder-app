## Elige el libro de búsqueda gratuita {#select}
1. Abre **Libros** y un libro con índice aceptado.
2. Toca **Usar para buscar** si no está **Seleccionado para buscar**.
3. Vuelve a **Buscar**.
Cambiar es gratuito y conserva los demás libros/índices. **Búsqueda en varios libros** busca en varios; archivos sincronizados no desbloquean la compra.
## Busca un título {#search}
1. Escribe parte del título.
2. Lee nombre del libro y página/rango de cada resultado.
3. Toca el adecuado para abrir el PDF.
Se busca texto del índice aceptado, no todo el PDF. Guarda OCR/ediciones antes. Un título puede aparecer en diferentes páginas o libros.
![Resultados con libros y rangos](/screenshots/es/search-results.png)
## Lee y añade un tema {#read}
Desplázate por el PDF y toca la página para ocultar/mostrar controles. + añade el tema a una [lista](/es/docs/playlists/).
Detalles también abre el PDF sin índice. Si abre una página incorrecta, [corrige el rango](/es/docs/manual-index/#pages), no el original.
## Resultado o PDF ausente {#missing}
Comprueba selección, índice guardado, ortografía y PDF; prueba un título corto. Un índice puede existir sin PDF, por lo que un resultado no garantiza lectura. Restaura el PDF correspondiente.
Tras corregir un índice, una referencia de lista puede conservar título/página anterior; revísala y reemplázala si hace falta. Consulta [Solución de problemas](/es/docs/troubleshooting/).
